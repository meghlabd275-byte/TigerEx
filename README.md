# TigerEx Exchange Platform

A comprehensive enterprise-grade cryptocurrency exchange platform inspired by Binance and Bybit architectures.

## Architecture

The platform consists of **48 top-level domains** covering:

### Trading & Markets
- Spot Trading
- Derivatives & Options Trading
- Margin Trading
- Copy Trading Platform
- Earn & Yield Platform
- Social Trading

### Core Infrastructure
- Core Exchange Engine (Matching, Risk, Market Data)
- Distributed Exchange Backend
- Realtime Messaging Backbone
- Ultra Low Latency Domain
- Caching Layer

### Security & Compliance
- Identity & Security
- Compliance & Regulatory
- Fraud Prevention
- Global Regulatory Partitioning
- Post-Trade Clearing System

### Enterprise Features
- Institutional Custody Platform
- API Gateway Platform
- Production Reliability Engineering
- Deterministic Recovery Platform
- Enterprise Data Platform

### Operations
- Internal Operations Platform
- Market Surveillance Console
- Infrastructure & SRE

### Frontend
- Frontend Superapp (Web + Mobile)
- Frontend Ecosystem

### External Integrations
- Blockchain & Web3 Infrastructure
- Staking & Validator Nodes
- Integrations & Partnerships

## Getting Started

```bash
# Install dependencies
npm install

# Run development
npm run dev

# Build
npm run build

# Docker
docker-compose up
```

## Tech Stack

- **Backend**: Node.js, TypeScript
- **Database**: PostgreSQL, Redis, Kafka
- **Infrastructure**: Kubernetes, Terraform
- **Frontend**: React, Next.js, React Native
