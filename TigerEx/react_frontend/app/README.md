## Installation

```bash
cd react_frontend/app
npm install
npm run build
```

## Tech Stack

- React 18+
- TypeScript
- Redux Toolkit (state management)
- React Query (server state)
- TailwindCSS
- TradingView Charts
- WebSocket for real-time data
